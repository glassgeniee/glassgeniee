GLASS GENIE WEBSITE

Files:
- index.html: the Glass Genie landing page.
- images/: add your own glass and aluminium project photographs here.

PHOTO FILENAMES EXPECTED BY THE WEBSITE
1. hero-glass.jpg                 Main hero/banner background photo
2. frameless-glass.jpg            Frameless glass service photo
3. aluminium-doors-windows.jpg    Aluminium doors/windows service photo
4. glass-balustrades.jpg          Glass balustrades service photo (if referenced by the page)
5. work-1.jpg                     Before: frameless glass project
6. work-2.jpg                     After: frameless glass project
7. work-3.jpg                     Before: aluminium door/window project
8. work-4.jpg                     After: aluminium door/window project

HOW TO ADD YOUR PHOTOS
- Copy your own photos into the images folder.
- Rename each photo to match the filename above, or edit the image src in index.html to match your chosen filename.
- Use .jpg filenames as listed unless you also update the HTML.
- Keep index.html in the repository root for GitHub Pages.

PUBLISHING ON GITHUB
Upload the contents of this folder to the root of your existing GitHub Pages repository. Do not upload only this ZIP file.

IMPORTANT GOOGLE TAG NOTE
This HTML is the Glass Genie redesign and may not include the Google tags from your currently published Pool Genie HTML. Before replacing the live index.html, compare and merge any existing Google tag, Google Ads conversion, Analytics, or Tag Manager code that you need to keep.
